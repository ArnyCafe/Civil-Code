# 民法註記本

給 iPad 使用的中華民國民法電子法典（網頁 App，可加到主畫面、離線使用）。

## 功能

- **民法全文**：1,439 條，依編／章／節目錄瀏覽；條文中「第○條」可點選跳轉。
- **註記**
  - 選取文字 → 螢光筆（黃／綠／藍／粉）、紅色底線、加註。
  - **旁註**：劃線註記與本條筆記顯示在條文旁的旁註欄（螢幕較窄時顯示在該段下方），螢光文字旁有 ①②③ 編號。
  - **點選顯示**：點螢光文字即跳出該段註記；設定中可改為「點選才顯示」，讓版面保持乾淨。
  - 每條可寫文字筆記、加標籤、加書籤。
  - **手寫模式**：按右上角筆形按鈕，用 Apple Pencil 直接在條文上書寫或螢光標記；手指仍可捲動。
- **判解・函釋**
  - 內建全國法規資料庫各條所附的「憲法法庭裁判」「大法官解釋」「判例（要旨）」。
  - 可將判解標記為「重要」、加個人筆記。
  - 可自行新增實務判決、法務部函釋、決議等（字號、日期、要旨、連結）。
- **新舊條文對照**：比對全國法規資料庫歷次版本（民國18年至今共 37 個版本），每條列出修正沿革時間軸；可任選兩個版本以「對照表」或「標示差異」檢視。尚未施行的修正（如第1223條）會特別標示。
- **搜尋**：條文、判解要旨、自己的註記；輸入 `184`、`184-1`、`第一百八十四條` 直接跳轉。
- **備份**：註記存在本機（IndexedDB）。設定 →「匯出備份」可存成 JSON，換裝置時「匯入」。

## 在 iPad 上使用

1. 將本專案以 GitHub Pages 發布（Settings → Pages → Deploy from a branch → 選此分支、`/ (root)`）。
2. 在 iPad 的 Safari 開啟網址，點「分享」→「加入主畫面」。
3. 之後從主畫面開啟即為全螢幕 App，離線也可使用。

> 註記只存在該裝置的瀏覽器中。請定期在「設定與備份」匯出備份。

## 更新資料

```bash
python3 tools/build_data.py --refresh   # 現行條文＋歷次版本 → data/civil.json
python3 tools/fetch_rulings.py          # 各條判解 → data/rulings.json
```

資料來源：法務部「全國法規資料庫」(law.moj.gov.tw)。本工具供學習參考，正式引用請以官方公布之法規與裁判全文為準。

## 檔案

| 路徑 | 說明 |

# 勞動事件法註記本（`labor/`）

給 iPad 使用的勞動事件法電子法典，網址為本站的 `labor/`（例：`https://<帳號>.github.io/Civil-Code/labor/`），可另外加到主畫面、離線使用。

## 功能

- **條文**：勞動事件法全 53 條（112.12.15 修正版），依章瀏覽；左側目錄可點條號直接跳轉。
- **我的註記（紅色小字）**
  - 選取文字 → 「上方註記」或「下方註記」，註記以**紅色小字**排在被註記文字的正上方或正下方，該行會自動撐開行距，不會蓋到條文。也可只劃螢光筆或紅線。
  - **顯示／隱藏**：右上角眼睛按鈕一次切換全部註記；每條標題右側「註記 n」按鈕切換該條；設定中也可切換。
  - **手指點選切換**：點紅字即隱藏該則註記（原處留一個小紅點），點被註記的文字即再顯示；長按紅字開啟選單（編輯、移到上方／下方、改顏色、刪除）。手寫模式中用手指點也有效。
  - 立法理由、判決摘錄、司法院問答、審理細則的文字也都可以加註記。
- **Apple Pencil 手寫**：按右上角筆形按鈕。筆寬可調到 **0.1**（滑桿 0.1–6，另有 0.1／0.2／0.3／0.5／0.8／1.2／2／3 快速鍵與即時預覽），可開關壓力感應；紅、藍、黑、綠筆與三色螢光筆、整筆橡皮擦、復原／重做。手指仍可捲動。
  - 每一筆畫綁定在起筆的段落上，字級改變或其他段落加了註記、引用小字時，筆跡會跟著自己的段落移動。
  - iPad 螢幕 1 個實體像素約為 0.5，筆寬低於此值時線條會變淡而非更細。
- **引用法條小字**：條文寫到其他法律（民事訴訟法、性別平等工作法、就業服務法、勞資爭議處理法、強制執行法、勞工保險條例等）時，在該項下方以小字顯示被引用條文的現行條文，並標示所引的項、款；條文中使用的概念若出自他法（如「團體協約」→團體協約法第2條、「工作規則」→勞動基準法第70條、「工資」→勞動基準法第2條第3款、「出勤紀錄」→勞動基準法第30條、「依工會法無得加入之工會」→工會法第6～8條）也以「相關」標示。可在設定改為「點選才顯示」或不顯示。
- **立法理由、修正理由、新舊條文對照**：各條 107 年制定理由；第 2、16、25、32 條另有 112 年修正理由與對照表（可切換「標示差異」）。理由中所引之法條也可展開小字。
- **判決**：最高法院重要民事裁判 30 段摘錄（第 2、3、6、11、12、14～16、29、30、35～38、40、46、49～51 條），為裁判原文逐字擷取，附裁判全文連結與「同旨」裁判。可標記重要、加筆記，也可自行新增判決、決議、法律座談會。
- **函釋・見解**：司法院民事廳「勞動事件常見問答」47 則，依條號歸類；勞動部或司法院函釋可自行新增（附勞動部法令查詢、司法院法學資料檢索連結）。
- **審理細則**：勞動事件審理細則、施行細則、律師酬金支給標準中明文引用本條的條文。
- **搜尋**：條文、理由、判決、問答、細則、我的註記；輸入 `37` 或 `第三十七條` 直接跳轉。
- **備份**：註記存在本機（IndexedDB），可在設定匯出／匯入 JSON。


資料來源：全國法規資料庫（法務部）、立法院法律系統（立法院國會圖書館）、司法院裁判書查詢系統、司法院網站。司法院問答需先存成 `.cache/labor/jy_qa.json`（見 `tools/build_labor.py` 說明）。本工具供學習參考，正式引用請以官方公布之法規與裁判全文為準。
