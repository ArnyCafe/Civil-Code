# 法典註記本

給 iPad 使用的電子法典（網頁 App，可加到主畫面、離線使用）。預設開啟**勞工退休金條例**，並收錄：

| 法規 | 條數 | 歷次條文與理由 | 判解 |
| --- | --- | --- | --- |
| 勞工退休金條例 | 69 | 立法院法律系統：每次制定／修正的條文與立法、修正理由 | 大法官解釋、憲法法庭判決 |
| 勞工退休金條例施行細則 | 63 | 全國法規資料庫歷史條文；附各次條文對照表（PDF）連結 | — |
| 勞動基準法 | 98 | 立法院法律系統（同上） | 大法官解釋、憲法法庭判決 |
| 民法 | 1,439 | 全國法規資料庫歷次版本比對 | 憲法法庭、大法官解釋、判例 |

## 功能

- **條號色塊**：每條條號以反白色塊標示，顏色依所屬章（或編）區分；條號下方以括號寫出**條旨**（本條在規定什麼）。條旨為編者整理，見 `tools/gists/*.tsv`。
- **引用他法**：條文提到「勞動基準法第十一條、第十三條但書…」等其他法律條文時，可點選看小字全文，條文下方「引用條文」也會以小字列出（設定中可預設展開）。
- **引用同法**：「第七條」「本條例第十一條」「前條」等可直接點選跳到該條。
- **沿革・理由**：修正時間軸、各版本立法理由／修正理由、任選兩版以「對照表」或「標示差異」比較。
- **判解・函釋**：內建全國法規資料庫各條的大法官解釋、憲法法庭判決；可自行新增法院判決、勞動部函釋（字號、日期、要旨、連結），標記重要、加筆記。
- **註記**
  - 選取文字 →「加註」：註記以**紅色小字**寫在該段文字的**上方或下方**（可逐則選擇）；也可改成旁註或點選才顯示。
  - **手寫**：按筆形按鈕，用 Apple Pencil 直接在條文上書寫。筆寬可從 **0.1 px** 起調整（滑桿＋0.1／0.3／0.6／1／2／4 快選），有紅、藍黑、黑、藍、綠與兩色螢光筆、橡皮擦、復原。筆跡以最近的字為錨點，改字級、行距或轉向時會跟著文字移動。設定中的行距「手寫／特寬」可在行間留出書寫空間。
  - **便利貼**：半透明、不遮住條文；選取文字後按「便利貼」，或在手寫工具列按「貼」後點條文即可貼上。拖曳「⋯」移動，「－」縮成小標籤。
  - **顯示／隱藏**：右上角眼睛按鈕切換全部註記；**手指點一下條文**可只切換該條，**兩指點一下**切換全部（設定中可關閉）。
  - 每條可寫文字筆記、加標籤、加書籤。
- **跨法律搜尋**：同時搜尋各法條文、條旨、立法理由、判解與自己的註記，可依法規篩選；輸入「勞基法 55」「勞退 24-2」「民法 184」直接跳到該條。
- **備份**：註記存在本機（IndexedDB）。設定 →「匯出備份」存成 JSON，換裝置時「匯入」（舊版「民法註記本」的備份也可匯入）。

## 在 iPad 上使用

1. 將本專案以 GitHub Pages 發布（Settings → Pages → Deploy from a branch → 選分支、`/ (root)`）。
2. 在 iPad 的 Safari 開啟網址，點「分享」→「加入主畫面」。
3. 之後從主畫面開啟即為全螢幕 App，離線也可使用。

> 註記只存在該裝置的瀏覽器中。請定期在「設定與備份」匯出備份。

## 更新資料

```bash
python3 tools/build_law.py all      # 勞退條例、細則、勞基法 → data/<id>.json、data/<id>-rulings.json
python3 tools/build_refs.py         # 被引用之其他法律條文 → data/refs.json；條旨 → data/gists.json
python3 tools/build_data.py --refresh && python3 tools/fetch_rulings.py   # 民法
```

資料來源：法務部「全國法規資料庫」(law.moj.gov.tw)、立法院法律系統 (lis.ly.gov.tw)。本工具供學習參考，正式引用請以官方公布之法規與裁判全文為準。

## 檔案

| 路徑 | 說明 |
| --- | --- |
| `index.html`、`css/`、`js/` | 網頁 App（無需建置） |
| `js/xref.js` | 條文引用解析（同法、他法、「同法」「前條」） |
| `js/ink.js` | Apple Pencil 手寫（以字為錨點） |
| `js/diff.js` | 逐字差異比對 |
| `data/laws.json` | 法規清單 |
| `data/*.json` | 各法條文、目錄、沿革與理由、判解、條旨、引用條文 |
| `sw.js`、`manifest.webmanifest` | 離線與加入主畫面 |
