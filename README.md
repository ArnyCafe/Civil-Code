# 法典註記本（強制執行法・民事訴訟法・民法）

給 iPad 使用的電子法典（網頁 App，可加到主畫面、離線使用）。預設開啟**強制執行法**，並內建民事訴訟法、民法供引用與跨法查詢。

## 功能

- **條號反白、依章節著色**：每條條號以所屬章節的顏色反白（強制執行法第二章各節分色），目錄也有對應色點；可在「我的註記」為單條改色，或在設定改為單色。
- **條旨**：條號下以括號寫明本條要旨（強制執行法 185 條、民事訴訟法 695 條、民法 1,374 條，編者整理）；可在「我的註記」自行改寫。
- **引用條文**
  - 同法條號（含「前條」「前二條」）可點，直接跳到該條。
  - 他法條號（如「民事訴訟法第四百零二條」「民法第一百五十一條」，含「同法」及「第○條、第○條」連續列舉）會在條文下方以**小字**列出內容，點一下跳出全文，可「前往」該法。
  - 「相關」：全國法規資料庫各條所列之相關法條；「參照」：強制執行法編者整理之參照條文（如第 4 條 → 民訴 §380、§416、公證法 §13…）。
- **紅字註記**：選取文字 →「紅字↑／紅字↓」，註記以**紅色小字放在那段文字的正上方或正下方**（只撐開那一行的行距，不改變斷行）。也可用螢光筆、紅底線劃線。另有「本條筆記」以紅色小字放在條文上方或下方。
- **Apple Pencil 手寫**
  - 預設 Apple Pencil 隨時可直接寫在條文上（手指仍用來捲動、選取文字；Pencil 點一下仍是點選）。
  - 工具列：筆（7 色）、螢光筆（4 色）、橡皮擦、復原／重做；**筆寬以 mm 調整，最細 0.05 mm**（預設 0.1／0.2／0.3…），可開關壓感；可開啟手指書寫。
  - 手寫模式中每條下方可「＋ 書寫空白」，留出手寫區。
- **便利貼**：半透明，貼在條文上不太遮住內容；可拖曳、縮放、收合、換色、調透明度。
- **顯示／隱藏我的註記**：右上眼睛按鈕一鍵隱藏或顯示（可選擇隱藏手寫、紅字、便利貼、螢光）；隱藏時**點一下條文**即單獨顯示該條，**雙指輕點**條文可隨時切換該條，條號旁「註記」標籤也可切換。
- **判解・函釋**：內建全國法規資料庫各條的憲法法庭裁判、大法官解釋、判例；可自行新增判決、函釋、決議、法律座談會；標為「重要」者以小字顯示在條文下方。
- **新舊條文對照**：比對全國法規資料庫歷次版本（強制執行法 11 個版本、民訴 23 個、民法 37 個），時間軸＋對照表／標示差異。
- **立法理由**：每次制定、修正各有一欄，附官方沿革文字，可貼上立法理由或修正說明保存。
- **跨法搜尋**：同時搜尋三部法律的條文、條旨、判解與自己的註記；輸入「強執4-1」「民訴402」「民法184」直接跳轉。
- **備份**：註記存在本機（IndexedDB）。設定 →「匯出備份」；可匯入舊版「民法註記本」備份，舊註記會自動搬到民法。

## 在 iPad 上使用

1. 將本專案以 GitHub Pages 發布（Settings → Pages → Deploy from a branch → 選此分支、`/ (root)`）。
2. 在 iPad 的 Safari 開啟網址，點「分享」→「加入主畫面」。
3. 之後從主畫面開啟即為全螢幕 App，離線也可使用。

> 註記只存在該裝置的瀏覽器中。請定期在「設定與備份」匯出備份。

## 更新資料

```bash
python3 tools/build_data.py --refresh   # 條文、條旨、歷次版本 → data/<pcode>.json
python3 tools/fetch_rulings.py          # 判解、相關法條 → data/<pcode>.rulings.json、.rel.json
python3 tools/build_xref.py             # 他法被引用條文 → data/xref.json
python3 tools/apply_captions.py         # 只改條旨時：把 tools/captions/ 套進資料檔
```

要加入其他法律：在 `data/laws.json` 加一筆（pcode 見全國法規資料庫網址），再執行上面三個指令。

資料來源：法務部「全國法規資料庫」(law.moj.gov.tw)。各法條旨與強制執行法「參照」條文為編者整理。本工具供學習參考，正式引用請以官方公布之法規與裁判全文為準。

## 檔案

| 路徑 | 說明 |
| --- | --- |
| `index.html`、`css/`、`js/` | 網頁 App（無需建置） |
| `js/app.js` | 主程式：多法載入、閱讀區、詳細面板、搜尋、設定 |
| `js/refs.js` | 條文引用辨識（本法、他法、同法、前條、連續列舉） |
| `js/annot.js` | 紅字行間註記排版 |
| `js/ink.js` | Apple Pencil 手寫（以字級 em 為座標單位，字級改變仍可對齊；筆寬以 mm 設定） |
| `js/sticky.js` | 便利貼 |
| `js/diff.js` | 逐字差異比對 |
| `data/laws.json` | 內建法律清單 |
| `data/<pcode>.json` | 條文、目錄、條旨、各條修正沿革（B0010004 強制執行法、B0010001 民事訴訟法、B0000001 民法） |
| `data/<pcode>.rulings.json`、`.rel.json` | 各條判解、相關法條 |
| `data/xref.json` | 他法被引用條文、法規名稱、編者參照 |
| `tools/captions/`、`tools/related/` | 條旨與編者參照條文（原始檔） |
| `sw.js`、`manifest.webmanifest` | 離線與加入主畫面 |
