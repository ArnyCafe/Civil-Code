# 民法註記本

給 iPad 使用的中華民國民法電子法典（網頁 App，可加到主畫面、離線使用）。同一網站的 `ccp/` 另有[民事訴訟法註記本](#民事訴訟法註記本ccp)。

## 功能

- **民法全文**：1,439 條，依編／章／節目錄瀏覽；條文中「第○條」可點選跳轉。
- **註記**
  - 選取文字 → 螢光筆（黃／綠／藍／粉）、紅色底線、加註。
  - **旁註**：劃線註記與本條筆記顯示在條文旁的旁註欄（螢幕較窄時顯示在該段下方），螢光文字旁有 ①②③ 編號。
  - **點選顯示**：點螢光文字即跳出該段註記；設定中可改為「點選才顯示」，讓版面保持乾淨。
  - 每條可寫文字筆記、加標籤、加書籤。
  - **手寫模式**：按右上角筆形按鈕，用 Apple Pencil 直接在條文上書寫或螢光標記；手指仍可捲動。
- **判解・函釋**
  - 內建全國法規資料庫各條所附的「憲法法庭裁判」「大法官解釋」「判例（要旨）」。
  - 可將判解標記為「重要」、加個人筆記。
  - 可自行新增實務判決、法務部函釋、決議等（字號、日期、要旨、連結）。
- **新舊條文對照**：比對全國法規資料庫歷次版本（民國18年至今共 37 個版本），每條列出修正沿革時間軸；可任選兩個版本以「對照表」或「標示差異」檢視。尚未施行的修正（如第1223條）會特別標示。
- **搜尋**：條文、判解要旨、自己的註記；輸入 `184`、`184-1`、`第一百八十四條` 直接跳轉。
- **備份**：註記存在本機（IndexedDB）。設定 →「匯出備份」可存成 JSON，換裝置時「匯入」。

## 在 iPad 上使用

1. 將本專案以 GitHub Pages 發布（Settings → Pages → Deploy from a branch → 選此分支、`/ (root)`）。
2. 在 iPad 的 Safari 開啟網址，點「分享」→「加入主畫面」。
3. 之後從主畫面開啟即為全螢幕 App，離線也可使用。

> 註記只存在該裝置的瀏覽器中。請定期在「設定與備份」匯出備份。

## 更新資料

```bash
python3 tools/build_data.py --refresh   # 現行條文＋歷次版本 → data/civil.json
python3 tools/fetch_rulings.py          # 各條判解 → data/rulings.json
```

資料來源：法務部「全國法規資料庫」(law.moj.gov.tw)。本工具供學習參考，正式引用請以官方公布之法規與裁判全文為準。

# 民事訴訟法註記本（`ccp/`）

給 iPad 使用的民事訴訟法電子法典，網址為本站的 `ccp/`（例如 `https://<帳號>.github.io/Civil-Code/ccp/`），一樣可加到主畫面、離線使用。

## 功能

- **條號反白配色**：條號以白字反白，依「編」使用不同顏色（總則藍、第一審程序綠、上訴審紫、抗告橙、再審紅、第三人撤銷訴訟玫紅、督促褐、保全青、公示催告灰）；刪除條文為淺灰。目錄的各編也有同色標記。
- **條旨**：每條條號下方以括號標示本條要旨（例如第249條「（訴之駁回－訴訟要件及無理由）」），共 800 條，可在設定中隱藏。
- **紅色小字註記**：長按選取文字 →「上註」或「下註」，註記以紅色小字顯示在該段文字的**上方或下方**；也可用螢光筆（黃／綠／藍／粉）或紅色底線。本條筆記也以紅色小字顯示在條文上方或下方。
- **Apple Pencil 手寫**：筆寬可細到 **0.1 點**（滑桿 0.1–10，另有 0.1／0.3／0.6／1.2／2.5 快速鍵），可開關筆壓感應；紅、藍黑、黑、綠筆及螢光筆、橡皮擦、復原／重做。手指仍可捲動。
- **顯示／隱藏我的註記**：
  - 右上角眼睛：點一下全部顯示／隱藏；長按可分別開關「手寫、紅字註記、螢光、便利貼、重要判解小字、他法條文小字」。
  - **手指點一下條文**（空白處）即可顯示／隱藏該條自己的註記（設定可改為點兩下或關閉）；手寫模式中，手指點觸也能切換。
- **便利貼**：右上角便利貼按鈕 → 點條文任一處放置；半透明不遮住條文，可拖曳、縮放、換色（黃／粉／藍／綠）、調整濃淡、縮成小標籤。
- **同法條號一點即跳**：條文中的「第二十八條」「前條」「前二條」等可直接點選跳到該條，左下角「← 返回」回到原條文。
- **他法條文小字**：條文引用其他法律（如民法第151條、第1010條、破產法、消費者債務清理條例、刑事訴訟法、強制執行法）時，在條文下方以小字顯示相關條文；點選引用文字可看全文並連到全國法規資料庫。
- **判解函釋**：全國法規資料庫各條所附「憲法法庭裁判」「大法官解釋」「判例」；可標記★重要、加個人筆記，並自行新增判決、大法庭裁定、函釋、決議。標★與自建者會以小字顯示在條文下方。
- **新舊條文對照**：依立法院法律系統「法條沿革」，列出歷次制定、修正（含三讀、公布、施行日期），可任選兩版以對照表或標示差異比較，對照表下附該次修正理由。民國19／20年舊法同條號條文另列參考。
- **立法理由**：各次修正理由逐次列出。
- **雲端同步（claude.ai 版）**：在 claude.ai 以 Artifact 開啟時，註記另存一份在你個人私有的雲端空間，跨裝置同步；本機仍以 IndexedDB 儲存。也可在設定中匯出／匯入備份。
- **寬螢幕停靠**：橫向時條文詳細面板停靠在條文右側；條文欄固定寬度，直橫向換行位置相同，手寫不會偏移。

## 更新資料

```bash
python3 tools/ccp_build.py --refresh   # 現行條文、目錄、條旨、他法條文、沿革與立法理由 → ccp/data/law.json、hist.json
python3 tools/ccp_rulings.py           # 各條判解 → ccp/data/rulings.json
```

條旨在 `tools/ccp_gists.tsv`（條號<TAB>條旨），可直接修改後重跑 `ccp_build.py`。條文未寫明條號的他法引用（例如「期間之計算，依民法之規定」）對應哪些條文，設定在 `tools/ccp_build.py` 的 `GENERIC`。

資料來源：法務部「全國法規資料庫」（現行條文、判解）、立法院「法律系統」（歷次條文與立法理由）。條旨為本工具自行撰寫，供閱讀參考；正式引用請以官方公布之法規與裁判全文為準。
