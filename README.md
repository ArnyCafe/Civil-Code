# 法典註記本

給 iPad 使用的電子法典（網頁 App，可加到主畫面、離線使用）。預設開啟 **職業安全衛生法**，書架上另有其子法、相關勞動法規與民法、刑法，可跨法查詢。

## 法典書架

| 分類 | 法規 |
| --- | --- |
| 職業安全衛生 | 職業安全衛生法、施行細則、職業安全衛生設施規則、職業安全衛生管理辦法、職業安全衛生教育訓練規則、勞工健康保護規則、營造安全衛生設施標準 |
| 勞動法 | 勞動基準法、勞動基準法施行細則、勞動檢查法、勞工職業災害保險及保護法、性別平等工作法 |
| 基本法 | 行政罰法、中華民國刑法、民法 |

## 功能

- **條號反白上色**：條號以白字反白顯示，顏色依章別區分（職安法：總則藍、安全衛生設施綠、職場霸凌之防治紫、安全衛生管理青、監督與檢查琥珀、罰則紅、附則灰）。
- **條旨**：職安法每條條號下以括號寫明本條要旨。
- **內建註解**（點條號開啟右側面板）
  - **判決・函釋**：最高法院、最高行政法院判決中引用該條之段落（自動擷取、當事人姓名遮蔽、同旨判決合併）；判決所引用之勞動部（原勞委會）函釋。可自行新增判決、函釋並標記重要。
  - **立法理由**：立法院法律系統之制定及歷次修正理由（63、80、91、102、108、114 年）。
  - **新舊對照**：歷次條文對照表或標示差異；民國102年全文修正（原「勞工安全衛生法」）前之條次會標示「原第○條」。
  - **相關法條**：其他法律之相關條文（如職安法第25條 ↔ 勞基法第59、62、63條、民法第184、185、188條）、引用本條之子法、依本條授權訂定之子法。
- **引用條文**：條文中「第六條第一項」等同法條號可點選跳到該條；引用其他法典（如「勞動基準法第59條」）以虛線標示，點選以小字顯示該條全文；條文下方也以小字列出相關法條。
- **我的註記**
  - 選取文字 →「上方註記」「下方註記」：以**紅色小字**顯示在該段文字的上方或下方；也可劃線（黃綠藍粉、紅底線）。
  - **便利貼**：半透明，不遮住條文；可拖曳移動、拖右下角調整寬度、縮小。
  - **Apple Pencil 手寫**：紅、藍、黑、綠筆與黃、粉螢光筆；筆寬以公釐設定，最細 **0.05 mm**（常用 0.1／0.2／0.3…），可開關筆壓；手指仍可捲動。
  - **顯示／隱藏**：右上角眼睛按鈕一次隱藏全部自己的註記；或用**手指在條文上點兩下**切換該條（設定可改為點一下或關閉）。
  - 每條可寫文字筆記、加標籤、加書籤。
- **搜尋**：條文、條旨、判決、函釋、立法理由與自己的註記；可選「本法」或「全部法典」。輸入 `25`、`15-1`、`第十五條之一` 直接跳轉；輸入 `勞基法59`、`民法184` 跨法跳轉。
- **備份**：註記存在本機（IndexedDB）。設定 →「匯出備份」存成 JSON，換裝置時「匯入」。舊版「民法註記本」的註記與備份會自動移轉。

## 在 iPad 上使用

1. 將本專案以 GitHub Pages 發布（Settings → Pages → Deploy from a branch → 選此分支、`/ (root)`）。
2. 在 iPad 的 Safari 開啟網址，點「分享」→「加入主畫面」。
3. 之後從主畫面開啟即為全螢幕 App，離線也可使用。

> 註記只存在該裝置的瀏覽器中。請定期在「設定與備份」匯出備份。

## 更新資料

```bash
python3 tools/fetch_ly.py 職業安全衛生法 勞動基準法 勞動檢查法 勞工職業災害保險及保護法   # 立法理由
python3 tools/build_laws.py                       # 現行條文、章節、歷次版本 → data/law/*.json、data/laws.json
python3 tools/fetch_judgments.py search           # 檢索最高法院、最高行政法院判決
python3 tools/fetch_judgments.py fetch            # 下載判決全文
python3 tools/build_extra.py                      # 判決、函釋、授權子法、反查索引 → data/extra/osh.json、data/xref.json
python3 tools/build_data.py --refresh && python3 tools/fetch_rulings.py   # 民法
```

條旨、章別顏色、相關法條等人工整理內容在 `tools/curated_osh.py`。

資料來源：法務部「全國法規資料庫」(law.moj.gov.tw)、立法院法律系統 (lis.ly.gov.tw)、司法院裁判書系統 (judgment.judicial.gov.tw)。判決段落為程式自動擷取，函釋文字為判決所述內容，未必是函釋全文；勞動部「勞動法令查詢系統」之函釋可用面板上的連結查詢後自行新增。本工具供學習參考，正式引用請以官方公布之法規與裁判全文為準。

## 檔案

| 路徑 | 說明 |
| --- | --- |
| `index.html`、`css/`、`js/` | 網頁 App（無需建置） |
| `js/app.js` | 主程式（書架、閱讀、註記、搜尋） |
| `js/ink.js` | Apple Pencil 手寫（以字級 em 為座標單位，字級改變仍可對齊；筆寬以公釐設定） |
| `js/xref.js` | 條文引用解析（同法跳轉、他法小字） |
| `js/diff.js` | 逐字差異比對 |
| `data/laws.json` | 法典書架 |
| `data/law/*.json`、`data/civil.json` | 各法條文、目錄、沿革、歷次版本與立法理由 |
| `data/extra/osh.json` | 職安法判決、函釋、相關法條、授權子法 |
| `data/xref.json` | 各條被其他法典引用之反查索引 |
| `data/rulings.json` | 民法各條判解 |
| `sw.js`、`manifest.webmanifest` | 離線與加入主畫面 |
