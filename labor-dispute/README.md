# 勞資爭議處理法註記本

給 iPad 使用的勞資爭議處理法電子法典（網頁 App，可加到主畫面、離線使用）。

## 功能

- **條文全文**：67 條（含第47條之1），依章瀏覽；點本法條號（如「第十九條」）會跳出該條預覽，可「前往」。
- **紅色小字註記（上方／下方）**
  - 選取條文文字 →「上註」或「下註」，輸入註記，即以紅色小字排在該段文字的正上方或正下方。
  - 短註記直接排在文字正上／正下方（行間）；較長的註記排在該段落上方或下方，以 ①②③ 對應。
  - 內建 60 則編者註（要件、期限、實務見解出處），可在設定中關閉。
- **顯示／隱藏註記**
  - **手觸或 Apple Pencil 點一下**紅字（或其下方的紅點線、編號）即可隱藏或再顯示該則註記。
  - **圈選模式**（工具列的套索按鈕）：用 Apple Pencil 圈起或劃過多則註記，一次隱藏／顯示；可設定圈選後為「切換」「隱藏」或「顯示」。手指仍可捲動；也可開「手指」圈選。
  - 條號旁的「註 n」按鈕：整條註記一次切換；工具列「註」按鈕：全部顯示／隱藏。
  - 長按紅字：編輯、改到上方／下方、換色、刪除（內建編者註可「複製成我的註記」再修改）。
- **相關法條小字**：條文引用工會法、團體協約法、行政程序法、仲裁法、民事訴訟法等時，於該段下方以藍灰色小字顯示被引用的條文（指定項、款者只顯示該項款），點一下可收合。「另見」類（如勞動事件法第4、12、47條）預設收合。工會法、團體協約法全文可在目錄開啟。
- **重要判決・函釋**：內建最高法院、最高行政法院判決原文摘錄及勞委會／勞動部函釋，可標記重要、加筆記，或一鍵「做成紅字註記」；也可自行新增判決、函釋、裁決決定。
- **新舊條文對照**：全國法規資料庫歷次版本（民國19年至110年，共10版）。98年全文修正後條號重編，修正前條號以人工對照；可選任兩版以對照表或標示差異檢視，並可閱讀各版全文。
- **手寫**：Apple Pencil 直接在條文上書寫（預設紅筆）。
- **搜尋、書籤、標籤、備份**：註記存在本機 IndexedDB，設定中可匯出／匯入 JSON。

## 在 iPad 上使用

1. 以 GitHub Pages 發布本專案後，開啟 `…/labor-dispute/`。
2. Safari「分享」→「加入主畫面」，之後即為全螢幕 App，離線可用。

## 更新資料

```bash
python3 tools/fetch_labor_rela.py   # 各條判例、相關法條、授權子法 → .cache/ld/
python3 tools/build_labor.py        # → labor-dispute/data/law.json
```

內建編者註、判決、函釋與新舊條號對照表在 `tools/labor_curated.json`，可直接編輯後重新建置。

資料來源：法務部「全國法規資料庫」、司法院裁判書系統。本工具供學習參考，正式引用請以官方公布之法規與裁判全文為準。
